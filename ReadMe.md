# 呆猫（Dai Cat）Mod 项目企划

**游戏版本：** RimWorld 1.7

**模组类型：** 可爱动物换皮 + 丰富互动

## 1. 项目目标

制作一只以参考图片为原型的「呆猫」，将它加入 RimWorld，作为一种可以驯养的动物。

这个模组不追求复杂的游戏机制，主要精力放在外观、动画和互动上。

目标是让呆猫看起来可爱、有生命感，让玩家愿意长期饲养它。

## 2. 外观要求

必须严格按照我提供的图片制作：

- 深蓝色猫咪连体服。
- 米黄色脸部。
- 大眼睛和小嘴巴。
- 两只巨大的尖耳朵。
- 圆滚滚的身体。
- 短小的手脚。
- 整体保持原图的 Q 版比例。

**不允许随意改变外观，不需要装备、武器或其他服装。**

## 3. 动画要求

希望呆猫拥有丰富、自然的动作：

- 待机：呼吸、眨眼、耳朵轻微晃动。
- 行走：小短腿交替运动，身体上下摇晃。
- 奔跑：快速移动，身体自然前倾。
- 睡觉：蜷缩身体，有呼吸动作。
- 进食：有专门的吃东西动作。
- 玩耍：打滚、蹦跳、伸懒腰。
- 互动：被抚摸时表现开心。
- 受惊：遇到危险时表现害怕。

所有动作都应该尽量流畅，避免僵硬的图片切换。

## 4. 互动要求

呆猫不能只是一个会移动的动物，希望它有自己的生活习惯。

包括：

- 自己寻找食物。
- 自己寻找地方睡觉。
- 在殖民地自由活动。
- 偶尔发呆、打滚、玩耍。
- 主动靠近殖民者。
- 可以被殖民者抚摸。
- 可以与殖民者建立亲密关系。
- 可以与其他呆猫互动。
- 遇到危险会害怕和逃跑。

希望这些行为能够自然随机发生，而不是全部需要玩家手动触发。

## 5. 游戏功能

呆猫作为正常动物，需要支持：

- 自然生成。
- 驯服。
- 饲养。
- 进食。
- 睡觉。
- 受伤。
- 死亡。
- 正常存档和读档。

不需要复杂的战斗、职业、技能和装备系统。

## 6. 美术质量

这是整个模组最重要的部分。

希望达到精品 RimWorld 模组的美术水准：

- 精细的角色贴图。
- 完整的四方向表现。
- 高质量动画。
- 自然的动作过渡。
- 清晰的细节和光影。
- 不同动作之间保持外观一致。

不能只用一张静态图片代替所有动画。

## 7. 开发顺序

按照以下顺序开发：

**第一步：** 制作呆猫四方向外观，确认是否符合参考图片。

**第二步：** 制作待机、行走、奔跑动画。

**第三步：** 将呆猫放入 RimWorld，确保它能正常作为动物活动。

**第四步：** 增加睡觉、进食、打滚、蹦跳等动作。

**第五步：** 增加抚摸、亲近、玩耍等互动。

**第六步：** 完善音效、细节和性能，制作正式发布版本。

## 8. 最终目标

制作一只外观可爱、动作丰富、行为自然的呆猫。

它不需要强大的能力，也不需要复杂的玩法。

只希望玩家在殖民地里看到它跑来跑去、睡觉、打滚、主动靠近殖民者时，会觉得非常可爱。

**核心理念：让呆猫成为一只真正有生命感、让玩家舍不得卸载的动物。**
